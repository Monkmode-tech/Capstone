# Dating App
This is a simple dating app built using Swift and SwiftUI. The app allows users to swipe through potential matches, and view their swip hostory.
## Features
- Swipe left or right to indicate interest in a profile.
- View a list of profiles that have been swiped right (liked).
- Simple and intuitive user interface.
## Installation
1. Clone the repository:
    ```bash
    git clone
    ```
2. Open the project in Xcode.
3. Build and run the application on a simulator or physical device.
## Usage
1. Swipe right on a profile to like it.
2. Swipe left on a profile to pass.
3. Tap the "History" label to view the list of profiles you have liked.

## UI Design
The user interface consists of the following components:
- A card view displaying the profile picture, name, age, and bio of the potential match
- Swipe gestures to like or pass on a profile
- A history view to display the list of liked profiles
- Simple and clean layout with a focus on user experience
